# 实现约定与复现边界

## 论文中的确定部分

- 先到货、后需求、期末计算持有和积压成本；固定订货时点、无到货交叉。
- 定理1对到货间隔中的累计需求取 `floor(b*n/(h+b))` 零基位置，扣到货前库存，截断为非负。分位数刚好落在整数边界时选择上端点最优解。
- Eq. (6) 用订货损失 + 需求辅助损失 + VLT辅助损失。
- 默认需求隐藏50、VLT层50/20、融合100/100、学习率0.001、动量0.85、batch64、Gaussian std0.01、ReLU、dropout0.2，来自Table B.1。
- 基库存均值/方差用过去180天。BM1总需求预测和BM2每日预测分开训练（论文尾注）。

## 未完整指定、由本项目明确选择的部分

- MQRNN：LSTM编码器、一次生成全局与各horizon上下文、共享局部解码器；不是声称恢复了作者未公开的源码。
- 隐层ReLU，输出softplus保证非负。需求模块同时预测均值和七个分位数；新增50%用于论文中位数图。
- 订货量MSE；需求均值MSE + pinball；VLT MSE；两个辅助权重均0.1。原文未给这些确切值。
- Adam未沿用上一版演示；这里采用与动量参数一致的SGD，学习率按 `lr/(1+1e-4*step)` 衰减。这是对原文未说明衰减形式的选择，不是L2权重衰减。
- 每个窗口除以 `max(历史均值,1)` 缩放需求、库存与订货目标；选择验证损失最低的权重，最多60轮、12轮不改善早停、梯度范数裁剪10。
- LightGBM：最多300树、learning_rate .03、15 leaves、min_child_samples10、验证早停20；这些原文未给出。

## 仅依赖现有数据的实验设定

销量文件5×457是唯一足够构造时间学习窗口的已公开材料。股票库存示例2条、VLT示例1条与销量脱敏ID不能可靠拼接，特征占位列也为空，故不伪造数据连接。

L固定为唯一示例4.970532407天向上取整5天；R设为7天。L<R使每次复核前上一笔已经到货，避免在途特征缺失时暗中忽略订单。不是拿这一行推断五SKU真实供应商参数。

训练状态为 `mean(past180)*(L+R)*cover`，cover∈{0,.5,1}；这是状态空间取样，不是观测库存。真实销量保持不变。每7天取一个订单窗口。60%/20%/20%时间分区内目标窗口完整落在区间，跨区窗口丢弃。最小20%训练量取每SKU训练时间前缀，并报告实际行数，不说成20% SKU。

主评价取最后30天，初始库存统一规则，库存/订单跨天持续。各策略独立拥有自己的库存状态和到货队列。末尾到货超出评价期的订单不下单；OPT在最后区间按有限剩余需求计算，其他策略沿用正常保护期，因此不额外声称消除了终端效应。

BM1/BM2使用固定已知L计算保护期（不使用VLT网络输出）。VLT模块仍参与辅助损失和融合，但固定目标不足以证明随机交货期预测有效。BM分位数在验证期最后30天的仿真上选择；该阶段也未接触测试窗口。
